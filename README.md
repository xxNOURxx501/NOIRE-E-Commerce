# 🕯️ NOIRÉ — Premium Scented Candles

> **Light the night.**

A mini e-commerce website for hand-poured scented candles, built as a university JavaScript project.

---

## ✨ About NOIRÉ

**NOIRÉ** is a small independent candle brand built around a simple idea:

> *A small flame can change the feeling of an entire room.*

This website was created as a **beginner-friendly JavaScript project** to demonstrate core web development skills, including DOM manipulation, Local Storage, and CRUD operations — all wrapped in a unique, elegant, dark-themed design.

---

## 🎯 Features

### 🏠 For Visitors
- **Home Page** — Hero section, featured scents, shop by mood, and offers carousel
- **Collection Page** — Browse all candles with:
  - Search (icon toggle)
  - Category filter (Calm · Warm · Romantic · Fresh)
  - Sort options (Price, Name, Default)
- **About Page** — Brand story, vision, mission, and contact info
- **Shopping Cart** — Add products, adjust quantities, and checkout

### 👤 For Users
- **Sign Up** — Create a new account
- **Login** — Secure authentication with Local Storage
- **Cart** — Persistent shopping cart (survives page refresh)
- **Checkout** — Place orders and track them

### 👑 For Admins
- **Dashboard** — Full admin panel with:
  - Total Products / Users / Orders stats
  - Product Management (Add / Edit / Delete / Search)
  - User Management (Add / Delete)
  - Recent Orders table
- **Protected Access** — Only admins can access the dashboard
